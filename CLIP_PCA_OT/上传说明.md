# 上传到 GitHub 的步骤

服务器无法直连 GitHub，需要在你本地（能访问 GitHub 的机器）操作：

## 1. 下载上传包

```bash
# 在本地 Mac 上执行
scp -P 16168 -r gyf@10.96.128.85:/home/gyf/upload/CLIP_PCA_OT ~/Downloads/
```

或使用你喜欢的 SFTP 工具下载 `/home/gyf/upload/CLIP_PCA_OT` 文件夹。

## 2. 本地推送

```bash
cd ~/Downloads/CLIP_PCA_OT
git init
git remote add origin https://github.com/LeoLibra338/CLIP_PCA_OT.git
git add .
git commit -m "PCA-OT: zero-parameter CLIP fine-tuning with retrieval-monotonicity trade-off"
git push -u origin main
```

如果远程仓库是空的，第一行用：
```bash
git init -b main
```

## 已排除的内容
- `data/train2017/`、`data/docci/` 图片（几十 GB）
- `weights/` 模型权重
- `train/output/` 训练日志和 checkpoint
- 所有 `__pycache__`

- `train/` — 训练代码（含 ot_lambda）

- 实验记录 md（experiment_results.md 等）
- 论文计划（paper_plan.md、paper_advice.md）
